# Multi-Modal Spatial Analysis of CRLM Recurrence: A "Seed and Soil" Framework

## 1. Research Intuition and Target

### 1.1 Biological Rationale: "Seed and Soil" Hypothesis

**"Seed" Component: Malignant Cell Heterogeneity**
- **Core Tumor (CT)**: Contains stem-like, metabolically flexible malignant cell subtypes that drive treatment resistance
- **Invasive Margin (IM)**: Harbors EMT-activated, invasion-competent malignant cells that enable metastatic spread
- **Hypothesis**: Specific malignant cell programs in CT/IM predict treatment response and recurrence risk

**"Soil" Component: Microenvironment Permissiveness**  
- **Peritumor (PT)**: Creates immune-suppressive, CAF-activated niches that support tumor cell survival and growth
- **Hypothesis**: Microenvironment composition determines whether circulating tumor cells can establish recurrent metastases

### 1.2 Clinical Target
**Primary Objective**: Distinguish treatment efficacy (chemotherapy vs. combination therapy) and predict recurrence in initially resectable CRLM through spatial molecular signatures

**Clinical Impact**: Enable precision treatment selection and personalized recurrence risk stratification

## 3. Analytical Framework

### **Phase 1: Reference Construction and Cell Program Discovery**

#### **Step 1: scRNA-seq Integration**
```
Objective: Build comprehensive malignant cell reference atlas
Data: 4 external + 1 internal (6 IM) scRNA-seq datasets
Methods:
- Harmony/Seurat integration for batch correction
- CNV analysis for malignant cell identification
- Quality control: doublet removal, cell cycle regression
Output: Integrated malignant cell atlas with defined cell states
```

#### **Step 2: Malignant Cell Program Identification**
```
Objective: Define functional programs aligned with IMC markers
Target Programs:
- Proliferation: MKI67, PCNA → Ki67 (IMC)
- Metabolism: GLUT1, HK2, FASN → GLUT1, HK2, FASN (IMC) 
- Hypoxia: CA9, VEGFA → CA-IX, VEGF (IMC)
- EMT: VIM, CDH1 → Vimentin, EpCAM (IMC)
- Stemness: LGR5, CD44 → EpCAM, CD57 (IMC)
Methods: Gene set scoring, NMF, trajectory analysis
Output: Gene signature matrix for each malignant program
```

### **Phase 2: External Validation and Reference Building**

#### **Step 3: Bulk RNA Deconvolution**
```
Objective: Test clinical relevance of identified programs
Data: External bulk RNA-seq cohort with DFS
Methods: CIBERSORTx using scRNA-seq reference
Analysis: Program abundance vs DFS survival analysis
Output: Clinical validation of malignant cell programs
```

#### **Step 4: Comprehensive Cell Type Annotation**
```
Objective: Create reference for spatial transcriptomics analysis  
Cell Types:
- Immune: CD3, CD4, CD8, FOXP3, CD68, CD163 signatures
- Stromal: FAP, ACTA2, COL1A1 signatures
- Endothelial: PECAM1, VWF signatures  
- Hepatocytes: ALB, CYP signatures
Methods: Marker-based signature scoring
Output: Multi-lineage cell type reference atlas
```

#### **Step 5: Spatial Transcriptomics Validation**
```
Objective: Validate tumor budding and spatial patterns
Data: 2 external Visium datasets
Methods: 
- Spot deconvolution using scRNA-seq reference
- Spatial domain identification
- Tumor budding region detection (high malignant + EMT)
Output: Spatial pattern validation of invasion programs
```

### **Phase 3: IMC Core Analysis - "Seed" Characterization**

#### **Step 6: Malignant Cell States in Spatial Context**
```
Objective: Map scRNA-seq programs to spatial protein data
Data: 35-patient IMC cohort (CT + IM regions)

Step 6.1 - Regional Composition Analysis:
- Map gene programs to protein expression signatures
- Quantify program abundance: CT vs IM
- Statistical testing: Regional distribution differences
- Spatial metrics: Program co-localization, gradients

Step 6.2 - Clinical Correlation Analysis:
- Survival analysis: Program abundance vs RFS
- Treatment stratification: Chemo vs Chemo+targeted response
- Multivariable Cox models with clinical covariates
- Treatment interaction effects

Methods: 
- Protein signature scoring based on gene programs
- Spatial statistics (Moran's I, Geary's C)
- Cox proportional hazards models
- Interaction testing

Output: Treatment-specific malignant cell biomarkers
```

#### **Step 7: Tumor Budding Characterization**
```
Objective: Deep dive into invasion biology at tumor margin
Data: IM region from 35-patient IMC cohort

Analysis:
- Identify budding foci: Single/small clusters of tumor cells
- Characterize budding phenotype: EMT markers, invasion programs  
- Spatial metrics: Budding density, distance from main tumor
- Cellular interactions: Budding cell neighbors
- Clinical correlation: Budding grade vs recurrence risk

Methods:
- Morphological detection algorithms
- Spatial point pattern analysis
- Neighborhood enrichment analysis
- Survival modeling

Output: Invasion-competence signatures and clinical correlates
```

### **Phase 4: Spatial Ecosystem Analysis**

#### **Step 8: Spatial Interaction Networks**
```
Objective: Map cell-cell communication and spatial organization
Data: Full 35-patient IMC cohort (all regions)

Analysis:
- Cell-cell proximity analysis (Squidpy/spatstat)
- Interaction strength quantification
- Spatial domains and communities
- Distance-dependent associations
- Regional interaction differences (CT vs IM vs PT)

Methods:
- Spatial statistics (Ripley's K, pair correlation)
- Graph-based community detection
- Distance decay analysis
- Permutation testing

Output: Spatial interaction maps and network signatures
```

#### **Step 9: Peritumor "Soil" Analysis**  
```
Objective: Identify microenvironment factors enabling recurrence
Data: PT region from 35-patient IMC cohort

Analysis:
- Immune infiltration patterns: CD8/Treg ratios, spatial distribution
- CAF activation zones: FAP+, Alpha-SMA+ regions
- Immune exclusion analysis: Cell-free zones around tumor
- Vascular patterns: VEGF+ regions, vessel density
- Treatment-specific microenvironment changes

Methods:
- Spatial domain analysis
- Immune landscape characterization
- Distance-based metrics from tumor boundary
- Treatment stratified analysis

Output: "Soil permissiveness" signatures for recurrence prediction
```

#### **Step 10: PT Pathway Analysis**
```
Objective: Transcriptional validation of microenvironment findings
Data: 9 PT spatial transcriptomics samples

Analysis:
- Differential expression: Recurrence vs non-recurrence
- Pathway enrichment: Immune, metabolism, ECM remodeling
- Spatial gradient analysis: Distance-dependent gene expression
- Cross-platform validation: Spatial transcriptomics vs IMC
- Immune infiltration deconvolution

Methods:
- Differential expression analysis (DESeq2, EdgeR)
- Gene set enrichment analysis (GSEA)
- Spatial autocorrelation analysis
- Correlation analysis with IMC features

Output: Transcriptional programs driving microenvironment permissiveness
```

### **Phase 5: Clinical Translation**

#### **Step 11: H&E Model Development**
```
Objective: Translate molecular signatures to routine pathology
Data: H&E images from 35 patients + molecular ground truth

Training Strategy:
- Ground truth: Molecular signatures from IMC/spatial transcriptomics
- Architecture: Multi-task CNN with attention mechanisms
- Features: Regional patch extraction (CT/IM/PT)
- Multi-task targets: Predict molecular programs simultaneously

Analysis:
- CT: Nuclear morphology → stemness/metabolism signatures
- IM: Budding patterns → invasion signatures
- PT: Lymphocyte density → immune signatures
- Interpretability: Grad-CAM, attention visualization

Methods:
- Deep learning (ResNet, Vision Transformer)
- Multi-task learning framework
- Cross-validation with molecular stratification
- Explainable AI techniques

Output: H&E-based treatment selection and prognosis tool
```

#### **Step 12: Independent Validation**
```
Objective: Validate H&E model in external cohort
Data: Independent H&E cohort with survival data

Validation Strategy:
- External test cohort evaluation
- Performance metrics: C-index, AUC, calibration plots
- Clinical utility assessment: Decision curve analysis
- Comparison with existing tools: RAS status, clinical scores
- Multi-center generalizability testing

Methods:
- External validation without retraining
- Bootstrapping for confidence intervals
- Clinical impact modeling
- Cost-effectiveness analysis

Output: Clinical-grade diagnostic tool with performance benchmarks
```
