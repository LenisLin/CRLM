CAIX+ cholangiocytes in the peritumor region represent a **stress-induced cellular state** that creates a pro-metastatic niche, serving as a biomarker for recurrence risk in CRLM patients.

### **Key Innovation:**
- First study to identify **non-malignant epithelial reprogramming** as a recurrence predictor
- Discovers that the "soil" preparation extends beyond tumor cells to normal liver architecture

## **Executable Step-by-Step Plan**

### **Phase 1: Cholangiocyte Identification & Mapping (Week 1)**

```python
# Step 1.1: Define cholangiocytes
Cholangiocytes = EPCAM+ AND CK20- cells in PT and IM regions

# Step 1.2: Create spatial networks
For each region (PT, IM):
    - Build connectivity graph at 20μm, 50μm, 100μm distances
    - Calculate network metrics (cluster size, density, connectivity)
    
# Step 1.3: Initial CAIX characterization
    - Measure CAIX intensity per cholangiocyte
    - Create heatmaps of CAIX expression
    - Compare PT vs IM CAIX levels (expect: IM > PT)
```

**Expected Output:** 
- Cholangiocyte spatial maps for all 89 samples
- CAIX gradient confirmation (higher in IM than PT)

### **Phase 2: Zone-Based Analysis (Week 2)**

```python
# Step 2.1: Define cholangiocyte zones
For each connectivity distance (20, 50, 100μm):
    - Identify connected cholangiocyte clusters
    - Expand boundaries by radius to create "zones"
    - Label zones as CAIX-high vs CAIX-low (median split)

# Step 2.2: Zone composition analysis
For each zone:
    - Count cell types within zone boundaries
    - Calculate immune/stromal/epithelial ratios
    - Compare R vs NR patients (PT samples only)
```

**Expected Output:**
- Zone maps with CAIX status
- Cell composition tables for each zone type
- Initial R vs NR differences

### **Phase 3: Treatment-Stratified Analysis (Week 3)**

```python
# Step 3.1: Four-way stratification
Groups = [Chemo_R, Chemo_NR, Combo_R, Combo_NR]

# Step 3.2: For each group, analyze:
    - CAIX+ zone prevalence
```

### **Phase 4: Molecular Characterization (Week 4)**

## **Key Methodological Innovations**

1. **Spatial Network Analysis**: Using connectivity graphs to define functional zones rather than arbitrary distances
2. **IM-PT Gradient**: Leveraging two regions to infer tumor proximity effects
3. **Zone-Based Microenvironment**: Analyzing neighborhoods of connected cholangiocytes rather than individual cells

## **Critical Success Metrics**

1. **Biological Validation**:
   - CAIX expression higher in IM than PT (confirms gradient)
   - CAIX+ zones show distinct immune composition

2. **Clinical Performance**:
   - CSI score achieves AUC > 0.75 for recurrence prediction
   - Adds independent prognostic value to existing markers

3. **Translational Feasibility**:
   - H&E model captures >70% of IMC-defined information
   - Inter-observer reproducibility > 0.8

## **Potential Pitfalls & Solutions**

| **Challenge** | **Solution** |
|---------------|-------------|
| Few cholangiocytes in some samples | Pool similar patients for robust analysis |
| CAIX expression variability | Use relative rankings within each sample |
| Treatment confounding | Stratified analysis from the start |
| H&E translation difficulty | Focus on architectural rather than cellular features |
